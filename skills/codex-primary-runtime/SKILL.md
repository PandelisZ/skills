# Codex Primary Runtime

This skill is a container for sub-skills that provide runtime capabilities for creating documents using the MSGraph API.

## Sub-skills

### slides/
PowerPoint/Slides skill for creating .pptx presentation files using the MSGraph API.

### spreadsheets/
Excel/Spreadsheets skill for creating .xlsx workbook files using the MSGraph API.
